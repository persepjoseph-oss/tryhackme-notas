# Offensive Security Intro

**Fecha:** 31 de octubre de 2026

## Qué aprendí
- La seguridad ofensiva consiste en pensar como un atacante para encontrar fallos antes que los encuentre alguien malintencionado.
- Una web puede tener páginas ocultas que no aparecen en ningún enlace.

## Técnica
- `dirb http://sitio` prueba muchos nombres de páginas y muestra las que existen (descubrimiento de contenido).
- Código **200**: la página existe y responde.
- Código **301**: es una redirección, típica de un directorio.

## Qué me costó
- Al principio algunos comandos me dieron "Unknown command" por cómo los escribí o los pegué.
- Entender qué significaba cada código de respuesta del resultado.
